# 🧪 تست‌های امنیتی سیستم

این فولدر شامل مجموعه کامل تست‌های امنیتی برای بررسی تمام جنبه‌های امنیتی سیستم است.

## 📁 ساختار فایل‌ها

```
scripts/
├── test-security-auth.ts           # تست‌های احراز هویت
├── test-security-authorization.ts  # تست‌های کنترل دسترسی
├── test-security-bruteforce.ts     # تست‌های محافظت Brute Force
├── test-security-resources.ts      # تست‌های دسترسی به منابع
├── test-security-settings.ts       # تست‌های Settings API
├── test-security-complete.ts       # اسکریپت اصلی (اجرای همه تست‌ها)
├── SECURITY_TEST_GUIDE.md          # راهنمای کامل
└── README_TESTS.md                 # این فایل
```

## 🚀 دستورات سریع

### اجرای تست کامل امنیت
```bash
npm run test:security
```

### اجرای تست‌های جداگانه
```bash
npm run test:security:auth          # احراز هویت
npm run test:security:authz         # کنترل دسترسی
npm run test:security:brute         # Brute Force
npm run test:security:resources     # دسترسی منابع
npm run test:security:settings      # تنظیمات
```

- محافظت از API تنظیمات
- مدیریت لیست‌های سیاه/سفید IP

## 🔧 پیکربندی

### متغیرهای محیطی
تست‌ها از تنظیمات `.env` استفاده می‌کنند:
- `DATABASE_URL`: آدرس دیتابیس
- پورت 3000 برای سرور (پیش‌فرض)

### تنظیمات دیتابیس
قبل از اجرا، مطمئن شوید:
```bash
npx prisma migrate dev
npx prisma db seed
```

## ⚠️ توجه

1. **محیط تست**: این تست‌ها برای محیط development طراحی شده‌اند
2. **داده‌های موقت**: تست‌ها داده‌های موقت ایجاد و بعد پاک می‌کنند
3. **سرور در حال اجرا**: حتماً قبل از تست سرور را اجرا کنید
4. **تداخل با تست‌ها**: اجرای همزمان تست‌ها ممکن است باعث تداخل شود

## 🔍 عیب‌یابی

### تست‌های ناموفق
1. بررسی لاگ‌ها در کنسول
2. چک کردن تنظیمات دیتابیس
3. مطمئن شدن از اجرای migrations
4. بررسی دسترسی‌های کاربری

### مشکلات رایج

#### سرور در حال اجرا نیست
```bash
npm run dev
```

#### خطای اتصال دیتابیس
```bash
# بررسی DATABASE_URL در .env
# راه‌اندازی دیتابیس
npx prisma migrate dev
```

#### کاربر Admin وجود ندارد
```bash
# ایجاد seed data
npm run db:seed
```
