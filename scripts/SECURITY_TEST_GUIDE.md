# 🔐 راهنمای تست امنیت

این مجموعه تست‌های جامع برای بررسی همه جنبه‌های امنیتی سیستم طراحی شده است.

## 📋 فهرست تست‌ها

### 1. تست‌های احراز هویت (Authentication) 🔐
- ورود موفق با اطلاعات صحیح
- رد ورود با اطلاعات نامعتبر
- رد ورود با اطلاعات خالی
- دریافت اطلاعات کاربر جاری
- خروج از سیستم

### 2. تست‌های کنترل دسترسی (Authorization) 🛡️
- محافظت مسیرها بدون احراز هویت
- دسترسی Admin به منابع محدود
- محدودیت دسترسی کاربران عادی
- کنترل دسترسی به لیست کاربران
- کنترل ویرایش تنظیمات

### 3. تست‌های محافظت Brute Force 🔒
- ثبت تلاش‌های ورود ناموفق
- بلاک خودکار IP بعد از تلاش‌های زیاد
- غیرفعال شدن کاربر بعد از تلاش‌های زیاد
- ریست تلاش‌ها بعد از ورود موفق
- بررسی لیست سیاه IP

### 4. تست‌های دسترسی به منابع (Resources) 📁
- فیلتر پروژه‌ها بر اساس دسترسی
- سطوح دسترسی پروژه (VIEW, ADD, ADMIN)
- دسترسی‌های پوشه (canView, canEdit, canDelete)
- کنترل دسترسی به اسناد
- دسترسی کامل Admin

### 5. تست‌های Settings API ⚙️
- دریافت تنظیمات امنیتی
- به‌روزرسانی تنظیمات توسط Admin
- منع ویرایش توسط کاربران عادی
- مدیریت لیست سیاه IP
- تنظیم Audit Logging
- تنظیم Session Timeout

## 🚀 نحوه اجرا

### پیش‌نیازها

1. **اجرای سرور:**
```bash
npm run dev
```
سرور باید روی پورت 3000 در حال اجرا باشد.

2. **دیتابیس:**
دیتابیس PostgreSQL باید در دسترس و migrate شده باشد.

3. **کاربر Admin:**
حداقل یک کاربر Admin با username و password معتبر داشته باشید.

### اجرای تست‌ها

#### اجرای همه تست‌ها (پیشنهادی)
```bash
npx tsx scripts/test-security-complete.ts
```

#### اجرای تست‌های جداگانه
```bash
# تست احراز هویت
npx tsx scripts/test-security-auth.ts

# تست کنترل دسترسی
npx tsx scripts/test-security-authorization.ts

# تست Brute Force
npx tsx scripts/test-security-bruteforce.ts

# تست دسترسی منابع
npx tsx scripts/test-security-resources.ts

# تست Settings
npx tsx scripts/test-security-settings.ts
```

## 📊 خروجی تست‌ها

خروجی تست‌ها شامل موارد زیر است:

### نمایش نتایج
- ✓ PASS: تست موفق (سبز)
- ✗ FAIL: تست ناموفق (قرمز)

### خلاصه نتایج
- تعداد تست‌های موفق و ناموفق برای هر دسته
- درصد موفقیت
- نتیجه کلی

### پیشنهادات بهبود
در صورت وجود تست‌های ناموفق، پیشنهاداتی برای بهبود ارائه می‌شود.

## ⚠️ نکات مهم

1. **محیط تست:** این تست‌ها روی محیط development اجرا می‌شوند. برای production باید تنظیمات مناسب انجام شود.

2. **داده‌های تست:** تست‌ها کاربران و پروژه‌های موقت ایجاد می‌کنند که بعد از اتمام تست پاک می‌شوند.

3. **تنظیمات امنیتی:** برخی تست‌ها تنظیمات امنیتی را موقتاً تغییر می‌دهند و سپس بازگردانی می‌کنند.

4. **تلاش‌های ورود:** تست‌های Brute Force ممکن است تلاش‌های ورود زیادی ایجاد کنند که طبیعی است.

## 📝 توسعه تست‌های جدید

برای افزودن تست‌های جدید:

1. فایل تست جدید در `scripts/` ایجاد کنید
2. تابع `run*Tests()` را پیاده‌سازی کنید که آرایه‌ای از `TestResult` برگرداند
3. تست را به `test-security-complete.ts` اضافه کنید

مثال:
```typescript
interface TestResult {
  name: string;
  passed: boolean;
  message: string;
  details?: any;
}

export async function runMyTests(): Promise<TestResult[]> {
  const results: TestResult[] = [];
  
  // تست‌های خود را اینجا اضافه کنید
  
  return results;
}
```
